# widget-static-auth-landing — the element's landing (node step 660)

The home page of this element, drawn after the Stripe sample like the stores (`widget-static-storage-landing`, step 650-4): the page is
`bare`, this widget draws it from the page data blocks, a section is `block-section-head` and the blocks up to the next, its view chosen
by its `id` (`route` beside the hero, `solves`, `agent`, `turn-on`, `connect`, `hood`, `more`, `credits`; any
other `id` — the general view). Words only in the data (en, ru, `humanizer`); the machine copy comes from the blocks, `markdown.ts`
returns nothing. Claims checked against the element's README. The owner 2026-11-06: «… в своей главной странице … стиль и дизайн как у
новых таких как страйп, глубинная память».
